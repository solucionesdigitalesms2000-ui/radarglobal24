# Radar Global 24 — sitio web

## Estructura

```
index.html         -> página de inicio (secciones: Mundial, Regional, Profesiones, Especiales)
css/style.css        -> estilos de todo el sitio (paleta y tipografía del Brand Book oficial v1.0)
img/logo.png           -> logo oficial
img/portada.jpg          -> portada oficial
posts/                     -> una página HTML por cada publicación
```

## Cómo publicarlo gratis (GitHub Pages)

1. Cuenta gratuita en https://github.com
2. Repositorio nuevo (por ejemplo `radarglobal24`), público.
3. Sube el contenido de esta carpeta (index.html, css/, img/, posts/).
4. Settings → Pages → Branch: main → / (root) → Save.
5. En 1-2 minutos, la web queda publicada en `https://tu-usuario.github.io/radarglobal24/`

## Flujo diario para publicar contenido nuevo

1. Tú creas el contenido con tu propio proceso: el texto ya redactado y la imagen/infografía ya lista, siguiendo el Brand Book.
2. En el chat me pasas: el texto, la imagen, y la categoría (Radar Mundial / Radar Regional / Profesiones / Especiales / etc.).
3. Te entrego dos archivos: la página nueva del artículo (para `posts/`) y el bloque de tarjeta nuevo (para pegar en `index.html`).
4. Subes el archivo nuevo a `posts/` en GitHub (Add file → Upload files), subes la imagen a `img/`, y editas `index.html` con el lápiz ✏️ para pegar la tarjeta nueva en la sección correspondiente.
5. Commit changes — la web queda actualizada en minutos.
